Client-administrator:
Проблемы:
1. Возможность получить любые данные через файловое хранилище
2. Возможность вместо администратора подключиться к системе и получить все данные
3. Отсутствие аутентификации/авторизации для ролевого доступа
4. Отсутствие обезличивания персональных данных о пациентах
5. Ручная обработка данных администратором, большая возможность человечекой ошибки
6. Отсутствие логов дествий кто, когда, за какими данными обращался
7. Отсутствие шифрование данных на сервере, данные можно скачать на носитель
Client-lab:
1. Для получения результатов анализа клиенту нужно обращаться к доктору
2. Доктор может запрашивать любые результаты
3. Отсутствие аутентификации/авторизации для ролевого доступа
4. Отсутствие логов дествий кто, когда, за какими данными обращался
Doctor-client:
1. Доктор может просмотреть записи к любому специалисту
2. Отсутствие аутентификации/авторизации для ролевого доступа
3. Отсутствие логов дествий кто, когда, за какими данными обращался

Перечень типов данных
Все данные пропускаются через McAfee DLP для тегирования данных
Персональные данные - для ML сервисов данные маскируются, для администраторов данные которые ему не полагается видеть, шифруются
Финансовые данные - если данные запрашивает человек, то данные шифруются
Служебные данные - если данные запрашивает роль у которой нету доступа ко всем данным, то данные шифруются
Медецинские данные - шифруются
