Определить ключевые процессы и компоненты, затрагиваемые миграцией.

1. Необходимо ввести систему авторизации/аутентификации
2. Необходимо ввести сервис для обработки запросов на данные и для определениея роли пользователя
3. Необходимо перевести хранение данных из файловой системы в бд, для хранения файлов клиентов s3 хранилище с шифрованием
4. Необходимо использовать автоматическое тегирование информации для ролевого доступа и обозначения какие данные могут являться чувствительными
5. Настроить/создать сервис уведомлений
6. Необходимо создать сервис который будет динамически маскировать данные для аналитический задач или др.


Пояснения к диаграмме Исикавы (приоритет, от самого важного к менее важному):
1. Нанять персонал
2. Выстроить процессы
3. Настроить программное обеспечение
4. Наладить инфраструктуру

Как перечисленные причины мешают миграции:
1. Персонал. Люди являются самым ценным ресурсом. Без квалифицированного персонала работа будет выполняться долго и некачественно.
 Без должного количества персонала могут возникать переработки и вследствие чего ухудшение работы команды
2. Процессы. Без четкого плана как выполнять миграцию не будет планомерных взвешенных решений, работа будет выполняться хаотично
и время выполнения работы может сильно замедлиться.
3. Программное обеспечение. Без наличии лицензии на ПО придется использовать общедоступное, которое надо будет усилиями команды подстраивать под процессы команды.
4. Инфраструктура. Без настроенной инфраструктуры возможности команды по деплою нового функционала на прод
 будут сильно ограниченны, так же будет затруднительно тестирование новых фич, что увеличит время разработки и количество багов в системе.
